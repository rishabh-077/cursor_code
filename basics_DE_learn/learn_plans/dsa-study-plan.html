DE Special SQL + Data Engineering Essentials Ongoing from Week 1

These are non-negotiable for data engineering roles at Google. Practice SQL every single day alongside DSA — even just 1–2 problems a day compounds fast.

SQL (Practice Daily)

  • Window functions — RANK, ROW_NUMBER, LAG, LEAD
  • CTEs and recursive CTEs
  • Complex JOINs, self-joins, cross joins
  • GROUP BY, HAVING, ROLLUP
  • Subqueries vs CTEs trade-offs
  • → DataLemur.com (free, Google questions)
  • → StrataScratch.com (free)

Python for Data

  • List / dict / set comprehensions
  • collections.Counter, defaultdict, deque
  • Generators and itertools
  • Sorting with custom key functions
  • File I/O and CSV parsing
  • → LeetCode — solve in Python only

System Design (DE)

  • ETL vs ELT pipeline design
  • Star schema vs Snowflake schema
  • Batch processing vs streaming
  • CAP theorem, eventual consistency
  • Partitioning and indexing strategies
  • → Karan Pratap Singh's DE guide (GitHub)

Mock Interviews

  • Think out loud — Google values communication
